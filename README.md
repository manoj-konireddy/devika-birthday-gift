# Devika Birthday Surprise 🎂

A responsive birthday website + photo slideshow built with HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Tap **Add your photos** and choose Devika's pictures. Photos stay in the browser and are not uploaded.
4. Optional music: add a legally usable MP3 file named `romantic.mp3` inside the `audio` folder. Tap **Music off** to start it. Browsers require a tap before audio can play.
5. For sharing as a public link, upload the whole folder to a static hosting service such as GitHub Pages or Netlify. Keep the folder structure intact.

## Project files
- `index.html` — page structure
- `style.css` — responsive styling and animations
- `script.js` — photo picker, slideshow, music control, confetti, candle wishes
- `photos/` — optional folder for keeping your own photo copies (the page uses the photo picker)
- `audio/romantic.mp3` — optional music file; not included

## Personalize
Edit the birthday message directly in `index.html`. The page currently uses a romantic, warm-friendship tone.
